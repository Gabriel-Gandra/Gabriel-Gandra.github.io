# Gabriel Gandra | Currículo online

Site-currículo de **Gabriel Rodrigues Pinto Gandra**, Analista de Infraestrutura de TI em Belo Horizonte.

**Acesse:** https://gabriel-gandra.github.io

## A ideia

O site usa o universo do meu trabalho com infraestrutura: impressoras de etiqueta Zebra, ciclo de vida de ativos e cabeamento de rede.

- **Etiqueta de ativo:** ao abrir a página, uma impressora térmica imprime minha etiqueta, com foto pontilhada e código de barras real (CODE128). Dá para arrastar a etiqueta.
- **Patch panel:** cada cargo é uma porta RJ45. Conectar uma porta passa o cabo e mostra o que eu fazia naquele cargo.
- **Competências como etiquetas:** escolher uma competência acende as portas e as atividades onde ela foi usada.
- **Imprima sua etiqueta:** o formulário de contato monta uma etiqueta ao vivo e abre o e-mail com a mensagem pronta.
- Português, espanhol e inglês; tema claro e escuro; funciona no celular e só com o teclado; respeita quem desativa animações.

## Tecnologia

HTML, CSS e JavaScript puros, sem frameworks. Código de barras com [JsBarcode](https://github.com/lindell/JsBarcode) (MIT). Publicado com GitHub Pages. As decisões de design estão em [DESIGN.md](DESIGN.md).
