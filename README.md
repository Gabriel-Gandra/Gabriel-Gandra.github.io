# Gabriel Gandra · Currículo online

Site-currículo de **Gabriel Rodrigues Pinto Gandra**, Analista de Infraestrutura de TI em Belo Horizonte.

**Acesse:** https://gabriel-gandra.github.io

## O que tem no site

- Um chamado de ITSM animado que se resolve ao carregar a página
- Histórico profissional com filtro: escolha uma competência para ver onde ela foi usada
- Três idiomas (português, espanhol e inglês)
- Tema claro e escuro
- Formulário "Abrir chamado", que abre o e-mail com a mensagem pronta
- Currículo em PDF para download

Feito com HTML, CSS e JavaScript puros, sem frameworks. Publicado com GitHub Pages.
